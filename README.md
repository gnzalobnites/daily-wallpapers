# 🌄 Daily Wallpapers

[![Kotlin](https://img.shields.io/badge/Kotlin-1.9.x-7F52FF.svg?logo=kotlin)](https://kotlinlang.org)
[![Android](https://img.shields.io/badge/Android-7.0+-3DDC84.svg?logo=android)](https://developer.android.com)
[![Material You](https://img.shields.io/badge/Material%20You-Dynamic-FF6F00.svg?logo=materialdesign)](https://m3.material.io)

Daily Wallpapers trae automáticamente el **fondo de pantalla diario de Bing** a tu dispositivo Android. Cada día descarga una nueva imagen de alta calidad para que puedas mantener tu pantalla siempre renovada.

## ✨ Características

- 🌅 Descarga automáticamente la imagen diaria de Bing.
- 🖼️ Aplica el fondo en la pantalla de inicio, de bloqueo o en ambas.
- ⭐ Guarda tus imágenes favoritas para acceder a ellas cuando quieras.
- 📚 Mantiene un historial de los fondos descargados.
- 💾 Permite guardar cualquier imagen en la galería.
- ⏰ Actualización automática a la hora que elijas.
- 🌙 Compatible con el modo oscuro del sistema.
- 🎨 Compatible con Material You.
- 🌐 Disponible en español e inglés.

---

## 📱 Requisitos

- Android 7.0 o superior.
- Conexión a Internet para descargar las imágenes.
